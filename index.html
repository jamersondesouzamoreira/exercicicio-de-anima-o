CSS Animações

animation-name · animation-delay · alternate-reverse

animation-name

Pulsar

Um orbe que expande e contrai usando um nome de animação personalizado chamado pulsar.

@keyframes pulsar { ... }
animation-name: pulsar;
animation-delay

Escalonado

Cada ponto inicia com um atraso diferente, criando um efeito cascata por meio do animation-delay.

.dot:nth-child(2) {
  animation-delay: 0.18s;
}
alternate-reverse

Vai e Volta

A barra desliza de ponta a ponta usando animation-direction: alternate-reverse — invertendo o sentido a cada ciclo.

animation-direction:
  alternate-reverse;
